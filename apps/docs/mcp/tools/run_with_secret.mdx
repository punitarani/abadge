title: "run_with_secret"
description: "Run a command with a secret injected as an env var. Returns exit code, duration, output-line count, and truncation flag. Subprocess output text is never returned to the model. Secrets larger than 4 KB are rejected — use mount_secret instead."
---

`run_with_secret` is the workhorse MCP tool. It calls `access.mount` with `mountType: env`, spawns a subprocess with the secret in its environment, and returns a summary of the result. Subprocess stdout/stderr text is **never forwarded to the model**.

<Warning>
  Subprocess output text is not returned. The model receives only the exit code, duration,
  output-line count, and truncation flag. If the model needs to read subprocess output, route
  it through a separate audited channel (write to a file via `mount_secret`, then read back
  explicitly). This prevents all semantic-leakage vectors (base64, hex, URL-encoded, nth-char
  extraction, byte-split, etc.) that string-based redaction cannot catch.
</Warning>

<Warning>
  Secrets larger than 4 KB are rejected before spawn. Use
  [`mount_secret`](/mcp/tools/mount_secret) instead for large secrets (PEMs, kubeconfigs, SSH
  keys, TLS certificates).
</Warning>

## Input

| Field | Type | Required | Description |
|---|---|---|---|
| `itemId` | string | yes | ID of the item to inject |
| `field` | string | no | Named field for multi-field items |
| `command` | string | yes | Command to run |
| `args` | string[] | no | Command arguments |
| `envVarName` | string | no | Environment variable name. Defaults to `ABADGE_SECRET`. |
| `purpose` | string | no | Caller-declared purpose. Recorded in audit. |

## Output

```json
{
  "exitCode": 0,
  "durationMs": 42,
  "outputLineCount": { "stdout": 2, "stderr": 0 },
  "truncated": false
}
```

| Field | Description |
|---|---|
| `exitCode` | Subprocess exit code |
| `durationMs` | Wall-clock milliseconds from handler entry to subprocess completion |
| `outputLineCount` | Number of lines captured per stream. Text is not returned — this is a diagnostic count only. |
| `truncated` | `true` if either stream hit the 8 KB per-stream capture cap |

## Capture bounds

- Secrets larger than **4 KB** (`MAX_OUTPUT_BYTES`) are **rejected before spawn**. Use [`mount_secret`](/mcp/tools/mount_secret) for large secrets.
- Each stream is bounded to **8 KB** (`STREAM_CAP_BYTES`) to prevent OOM from a misbehaving subprocess.
- `truncated: true` is set when either cap dropped data.

## What the model sees

- The exit code
- Duration in milliseconds
- Whether stdout/stderr produced any lines (count only)
- The truncation flag

## What the model does not see

- Stdout or stderr text (in any form — plain, redacted, encoded, or truncated)
- Raw secret bytes
- Subprocess environment dump
- Filesystem paths
- The host's real environment variables

## Permission required

`mount_env` on the item, granted to the MCP agent. Local agents only.

## Errors

| Code | Cause |
|---|---|
| (runtime throw) | Secret exceeds 4 KB — use `mount_secret` instead |
| `PERMISSION_DENIED` | No matching `mount_env` permission |
| `MULTI_FIELD_ITEM` | Item has multiple fields and `field` was omitted |
| `FIELD_NOT_FOUND` | Specified field doesn't exist |
| `INVALID_CAPABILITY_LOCALITY` | The MCP agent isn't local |
| `ITEM_NOT_FOUND` | Item ID unknown or deleted |

Errors are returned as `{ error, code, hint, meta }` JSON content. See [error responses](/mcp/security#error-responses).

## Audit

`access.mount_env` — one row per call, with `surface: "mcp"`, the agent ID, the item ID, the field (if any), and the declared purpose.

## Example

The model emits:

```json
{
  "name": "run_with_secret",
  "arguments": {
    "itemId": "item_01HZ...",
    "field": "token",
    "command": "curl",
    "args": ["-fsSL", "-H", "Authorization: Bearer $ABADGE_SECRET", "https://api.example.com/me"],
    "envVarName": "ABADGE_SECRET",
    "purpose": "fetch user profile"
  }
}
```

The MCP server:

1. Resolves `token` from the item.
2. Spawns `curl ...` with `ABADGE_SECRET=<value>` in its env.
3. Captures stdout/stderr (internally, for line counting only — not forwarded to model).
4. Returns `{ exitCode, durationMs, outputLineCount, truncated }`.
