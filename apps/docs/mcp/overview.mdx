---
title: "MCP overview"
description: "Item-aware MCP tools for AI agents — secrets are injected into subprocesses, never into model context."
---

The abadge MCP server exposes item-aware tools to AI runtimes via [Model Context Protocol](https://modelcontextprotocol.io). It runs as a subprocess over stdio and is consumed by clients like Claude Desktop, MCP-aware IDEs, and custom agent runtimes.

The model **never receives raw secret material**. Tools either operate on metadata or inject secrets into subprocesses behind a redaction boundary.

## Transport

| Property | Value |
|---|---|
| Protocol | MCP |
| Transport | stdio |
| Server name | `abadge` |

## Quick reference

| Tool | Purpose |
|---|---|
| [`list_items`](/mcp/tools/list_items) | Item metadata only |
| [`run_with_secret`](/mcp/tools/run_with_secret) | Run a command with a secret injected as an env var. Output redacted, capped at 4 KB. |
| [`mount_secret`](/mcp/tools/mount_secret) | Mount a secret as a `0600` temp file. Returns an opaque `mountId`. Auto-deletes after 5 minutes. |
| [`release_mount`](/mcp/tools/release_mount) | Release a mounted secret early. |
| [`get_audit`](/mcp/tools/get_audit) | Fetch recent audit entries. |

## Auth at a glance

Two modes, in order of preference:

<Tabs>
  <Tab title="Keypair (preferred)">
    Set environment variables:

    ```bash
    export ABADGE_API_URL=http://localhost:8787
    export ABADGE_AGENT_ID=agent_...
    export ABADGE_PRIVATE_KEY_PATH=~/.abadge/agents/mcp.ed25519.jwk
    ```

    The MCP server runs an Ed25519 challenge / session exchange on startup and refreshes the `abs_...` token before it expires. No long-lived secret on disk.

    See [Authentication](/mcp/authentication) for the full configuration matrix and the `~/.abadge/config.json` fallback.
  </Tab>
  <Tab title="Legacy API key">
    ```bash
    export ABADGE_AUTH_TOKEN=abl_...
    ```

    The server emits a deprecation warning when this path is used. Prefer keypair sessions.
  </Tab>
</Tabs>
