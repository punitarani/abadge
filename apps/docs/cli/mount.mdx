---
title: "abadge mount"
description: "Resolve a secret and write it to a temporary file with 0600 permissions."
---

`abadge mount` resolves a secret and writes it to a temporary file. The CLI prints the file path so you can use it in subsequent commands.

The file is written with `0600` permissions. By default it lands at `<os.tmpdir()>/abadge-<uuid>`; pass `--path` to choose the location. The CLI does not track or auto-clean the file — remove it yourself when you're done.

## Usage

```bash
abadge mount --item <item-id>
abadge mount --item <item-id> --field private_key
abadge mount --item <item-id> --path /tmp/my-secret.txt
```

## Flags

| Flag | Description |
|---|---|
| `--item <id>` | Item ID (required) |
| `--field <name>` | Named field to mount (for multi-field items) |
| `--path <path>` | Target file path. Parent directories are created as needed. Defaults to `<os.tmpdir()>/abadge-<uuid>`. |

## Behavior

<Steps>
  <Step title="Resolve the secret">
    Same access path as `abadge run`: `POST /v1/access/{itemId}/use` with `delivery: file`, with daemon decryption for zero-knowledge items.
  </Step>
  <Step title="Write the file">
    The CLI writes the resolved secret value to `--path` (or a generated temp path), creating parent directories as needed, with `0600` permissions.
  </Step>
  <Step title="Print the path">
    The CLI prints `Mounted at: <path>` on stdout.
  </Step>
</Steps>

## Cleanup

`abadge mount` does not track the file or expire it. The file persists until you delete it manually.

```bash
# Manual cleanup
rm <path-printed-by-mount>
```

## Use cases

- Loading a TLS private key into nginx
- Passing an SSH key to `ssh -i`
- Feeding a service-account JSON to a Google Cloud client
- Anything that takes a `--key-file` style argument and not an env var

## Errors

| Error | Cause |
|---|---|
| `PERMISSION_DENIED` | No matching `use` permission |
| `MULTI_FIELD_ITEM` | Item has multiple fields and `--field` was omitted |
| `FIELD_NOT_FOUND` | Specified field doesn't exist |
| `INVALID_CAPABILITY_LOCALITY` | Trying to use a remote agent for `use` |
