## `abadge agent add`

Register a new agent. Generates an Ed25519 keypair on-device, stores the
private key in `~/.abadge/agents/`, and uploads the public key. For
`local_cli` and `local_mcp` kinds, the agent ID and private-key path are
also written to the matching `localAgents.*` config slot so that
`abadge run` and the MCP server find them automatically.

```bash
abadge agent add --name dev-laptop
abadge agent add --name dev-laptop --kind local_cli
abadge agent add --name mcp-host --kind local_mcp
abadge agent add --name ci-bot --kind remote
abadge agent add --name ci-bot --kind remote --bootstrap     # issue a one-time bootstrap token
abadge agent add --name ci-bot --kind remote --public-key ./key.jwk
```

| Flag | Required | Description |
|---|---|---|
| `-n, --name <name>` | yes | Agent display name |
| `-k, --kind <kind>` | no | `local_cli` (default), `local_mcp`, or `remote` |
| `-d, --description <text>` | no | Optional description (stored in `metadata.description`) |
| `--bootstrap` | no | Issue a one-time bootstrap token instead of generating a local keypair |
| `--public-key <path>` | no | Path to an existing Ed25519 public-key JWK to enroll |
| `--mcp-config` | no | After registering a `local_mcp` agent, print a Claude Desktop config snippet |
| `--json` | no | Print raw JSON |

<Note>
  Agents authenticate only with Ed25519 keypair sessions. There is no
  long-lived agent API key.
</Note>

### `--mcp-config` (local_mcp only)

```bash
abadge agent add --kind local_mcp --name claude-desktop --mcp-config
```

```json
{
  "mcpServers": {
    "abadge": {
      "command": "/Users/you/.abadge/bin/abadge-mcp",
      "env": {
        "ABADGE_API_URL": "https://api.abadge.io",
        "ABADGE_AGENT_ID": "agt_...",
        "ABADGE_PRIVATE_KEY_PATH": "/Users/you/.abadge/agents/agt_....ed25519.jwk"
      }
    }
  }
}
```

The binary path defaults to `${ABADGE_INSTALL_DIR:-~/.abadge/bin}/abadge-mcp`.

### Keypair registration

<Steps>
  <Step title="Generate keypair">
    The CLI uses WebCrypto to generate an Ed25519 keypair locally.
  </Step>
  <Step title="Upload the public key">
    `POST /v1/agents` is called with `publicKey` (JWK JSON) and metadata.
  </Step>
  <Step title="Store the private key">
    Written to `~/.abadge/agents/<agent-id>.ed25519.jwk` with `0600`
    permissions inside a `0700` directory.
  </Step>
  <Step title="Update config">
    For `local_cli` and `local_mcp` agents, `~/.abadge/config.json` gets
    `localAgents.cli` or `localAgents.mcp` populated.
  </Step>
</Steps>

Remote agents skip the config step — the CLI prints the agent ID, kind,
and path to the private-key file, plus a warning that you must configure
the remote service with those credentials yourself.

## `abadge agent list`

```bash
abadge agent list
abadge agent list --json
```

Output columns: `ID`, `Name`, `Kind`, `Locality`, `Enabled`, `Created`.

## `abadge agent rm <agent-id>`

Revoke an agent. Invalidates all active `abs_...` sessions and disables
future authentication.

```bash
abadge agent rm <agent-id>
```

Permissions are not deleted; they remain visible (and useless) until the
agent is removed or re-enabled.

## `abadge agent mcp-config <agent-id>`

Reprint the Claude Desktop config snippet for an already-registered
`local_mcp` agent.

```bash
abadge agent mcp-config agt_...
```

## Deprecated aliases

For backwards compatibility:

| Deprecated | Canonical |
|------------|-----------|
| `abadge agent register` | `abadge agent add` |
| `abadge agent revoke` | `abadge agent rm` |

The deprecated verbs print a deprecation notice on stderr and re-dispatch
to the canonical verb.
