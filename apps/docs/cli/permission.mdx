## `abadge permission create`

Grant one or more capabilities for an agent on an item. Multiple capabilities land atomically — either every row is written or none is.

```bash
# Single capability
abadge permission create \
  --agent-id <agent-id> \
  --item-id <item-id> \
  --capability reveal_plaintext

# Multiple capabilities — repeat the flag
abadge permission create \
  --agent-id <agent-id> \
  --item-id <item-id> \
  --capability reveal_plaintext \
  --capability mount_env \
  --capability mount_file

# Multiple capabilities — comma-separated
abadge permission create \
  --agent-id <agent-id> \
  --item-id <item-id> \
  --capability reveal_plaintext,mount_env,mount_file

# With expiry — applied to every capability in this batch
abadge permission create \
  --agent-id <agent-id> \
  --item-id <item-id> \
  --capability mount_env \
  --expires-at 2026-12-31T00:00:00Z
```

| Flag | Required | Description |
|---|---|---|
| `--agent-id <id>` | yes | Target agent |
| `--item-id <id>` | yes | Target item |
| `--capability <cap>` | yes | One of `read_ciphertext`, `reveal_plaintext`, `mount_env`, or `mount_file`. Repeat the flag or pass a comma-separated list to grant multiple capabilities at once. |
| `--expires-at <ts>` | no | ISO timestamp expiry; applied to every capability in this submission |
| `--json` | no | Print raw JSON |

The CLI rejects invalid combinations at create time. The capability matrix:

| Capability | Local + ZK | Local + SM | Remote + ZK | Remote + SM |
|---|---|---|---|---|
| `read_ciphertext` | ✓ | – | ✗ | – |
| `reveal_plaintext` | – | ✓ | – | ✓ |
| `mount_env` | ✓ | ✓ | ✗ | ✗ |
| `mount_file` | ✓ | ✓ | ✗ | ✗ |

## `abadge permission list`

```bash
abadge permission list
abadge permission list --agent-id <agent-id>
abadge permission list --item-id <item-id>
abadge permission list --json
```

| Flag | Description |
|---|---|
| `--agent-id <id>` | Filter to one agent |
| `--item-id <id>` | Filter to one item |
| `--json` | Print raw JSON |

Output columns: `ID`, `Agent`, `Item`, `Capability`, `Expires`, `Created`.

## `abadge permission revoke <permission-id>`

Revoke a permission immediately. In-flight access attempts that haven't yet checked the row see the deletion and are denied.

```bash
abadge permission revoke <permission-id>
```
