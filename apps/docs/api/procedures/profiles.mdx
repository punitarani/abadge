The `profiles` router manages credential namespaces. Each profile carries its own encryption root.

## `profiles.create`

**Tier:** `sessionProcedure`

<ParamField path="orgId" type="string" required>
  Owning organization.
</ParamField>
<ParamField path="name" type="string" required>
  Profile display name. Unique within the org.
</ParamField>
<ParamField path="description" type="string" />
<ParamField path="storageMode" type="string">
  `zero_knowledge` or `server_managed`. Defaults to `server_managed`.
</ParamField>

**Returns:** `{ id }`.

Errors: `PROFILE_ALREADY_EXISTS` if `(orgId, name)` collides.

## `profiles.bootstrap`

**Tier:** `sessionProcedure`

Initialize encryption state for a zero-knowledge profile.

<ParamField path="profileId" type="string" required />
<ParamField path="wrappedRootKey" type="string" required>
  XChaCha20-Poly1305 ciphertext of the root key under the KEK. `nonce || ciphertext+tag`, base64.
</ParamField>
<ParamField path="kdfSalt" type="string" required>
  16 random bytes, base64.
</ParamField>
<ParamField path="kdfParams" type="object" required>
  `{ algorithm, memory, iterations, parallelism, hashLength }`.
</ParamField>

**Returns:** `{ id }`.

Errors: `VAULT_ALREADY_EXISTS` if the profile is already bootstrapped.

## `profiles.rotateKey`

**Tier:** `sessionProcedure`

Generate a new root key and re-wrap every item DEK in a single transaction. Increments `keyVersion`.

<ParamField path="profileId" type="string" required />
<ParamField path="wrappedRootKey" type="string" required>
  New root key wrapped with the current KEK.
</ParamField>
<ParamField path="recoveryWrappedRootKey" type="string">
  New root key wrapped with the recovery key. Required if recovery is set up.
</ParamField>
<ParamField path="rekeyedItems" type="object" required>
  Map of `itemId` → new `encryptedItemKey`. Must include every item in the profile.
</ParamField>

**Returns:** `{ ok: true, keyVersion }`.

Errors: `ROTATE_KEY_INCOMPLETE` if any item is missing from `rekeyedItems`. `meta.missingItemIds` lists the omissions.

## Legacy: `vault.*`

Per-user vault procedures retained for web-app compatibility:

- `vault.bootstrap`, `vault.get`, `vault.changePassword`, `vault.setupRecovery`, `vault.rotateKey`

These will be removed in a future release. Prefer `profiles.*` for new integrations.
