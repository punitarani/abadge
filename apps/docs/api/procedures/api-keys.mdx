---
title: "apiKeys.*"
description: "Create, list, and revoke personal API keys for the management surface."
---

The `apiKeys` router manages **personal API keys** (prefix `abu_`). A personal API key lets a user script the management surface without a browser. Each key is bound to a `(user, org)` pair, created from the dashboard org Settings page, and sent as `Authorization: Bearer abu_...`.

<Warning>
  A personal API key resolves to a **session identity**, not an agent. It reaches only the `sessionProcedure` management surface (organizations, profiles, items metadata, agents, permissions, audit, settings). It is **structurally barred from the agent-gated `access.*` surface** — it can never reveal or mount secret values. Reading secrets still requires a keypair agent plus an explicit permission.
</Warning>

## `apiKeys.create`

**Tier:** `sessionProcedure` (browser session only — a personal API key cannot create another API key).

Scoped to the active organization; the key is owned by the calling user and that org.

<ParamField path="name" type="string" required>
  Human-readable label.
</ParamField>
<ParamField path="expiresAt" type="string">
  Optional ISO 8601 expiry. Omit for a key with no expiry.
</ParamField>

**Returns:**

```ts
{
  apiKey: string;        // full abu_... secret — shown ONCE
  key: UserApiKey;       // the stored record (no secret)
}
```

The secret is shown exactly once. The server stores only a SHA-256 hash plus an 8-character lookup prefix.

## `apiKeys.list`

**Tier:** `sessionProcedure`

List the caller's personal API keys in the active org. Secrets are never returned.

**Returns:** `{ keys }` — each entry includes `id`, `name`, `secretPrefix`, `enabled`, `expiresAt`, `revokedAt`, `lastUsedAt`, and `createdAt`.

## `apiKeys.revoke`

**Tier:** `sessionProcedure` (browser session only).

<ParamField path="keyId" type="string" required />

**Returns:** `{ ok: true }`.

Disables the key immediately. Subsequent requests with the revoked key fail authentication.

## Security properties

| Property | Behavior |
|---|---|
| Surface | Management only — every `sessionProcedure`; never `access.*` |
| Identity | Session identity (`kind: "session"`), never an agent |
| Secret values | Cannot reveal or mount — that requires a keypair agent + permission |
| Storage | SHA-256 hash + 8-char prefix; full secret shown once |
| Org scope | Bound to one `(user, org)` pair |
| Self-management | Cannot create or revoke other API keys (needs a browser session) |
| Expiry / revoke | Optional `expiresAt`; revocable at any time |

## Audit events

- `user_api_key.create`
- `user_api_key.revoke`
