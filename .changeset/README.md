# Changesets

Changeset files in this directory drive the version PR and GitHub Release flow for the abadge
release-managed packages: `@abadge/cli` (ships as the `abadge` binary) and `@abadge/mcp` (ships
as the `abadge-mcp` binary). Release-surface changes for either package should include a
changeset so the release workflow can open or update the version PR on `main`.
